篮子商品：双层原味板烧鸡腿麦满分、大脆鸡扒麦满分、新地、经典麦旋风、100% 苹果汁(盒装)、优品豆浆、原味板烧鸡腿麦满分、派、火腿扒麦满分、猪柳麦满分、脆薯饼、脆香油条、鲜萃咖啡、可乐。逐城合计 广州 最低（161.50 元）、 深圳 最高（163.75 元），极差 2.25 元，占 1.4%。 麦当劳在中国基本执行统一价格带，城市不是变量。

同款同码，价格能差多少只按商品编码配对，名称相同但编码不同的一律不算同款

商品最低最高价差幅度

同一份「脆香油条豆浆组合」最低 17.0 元、最高 28.5 元。这类差异多数不是菜单定价，而是门店维度的促销参与状态不同—— 有的门店挂着活动价，有的门店按原价卖。

哪家门店整体更贵该店可比商品中，高于同城中位价的占比与累计差额

深圳兴融二路（华融大厦）在 55 个可比商品里有 36 个高于同城中位价，累计贵 57.3 元，是本次样本里最明显的点位溢价门店。 写字楼、交通枢纽类门店的加价，比城市差异大一个量级。

门店的菜单宽度同一时段在售商品数量 · 下列为最窄 8 家与最宽 8 家（共 31 家样本）

最窄的是成都春熙路地铁站快捷小站（52 款），最宽的是广州体育东潮流站与武汉江汉路大汉口（99 款）。 快取小站的品类被压缩，想凑齐一顿完整早餐不一定凑得出来。

同名不同码（真实样本）

    这意味着什么

    • 「精选麦满分套餐」在编码层面是 3 个不同商品，价格 13.5 / 15.3 / 28.5 元
    • 如果只按名字匹配，会把 28.5 元的双人份 和 13.5 元的单人份 算成同一个商品，得出「同款相差 111%」的假新闻
    • 本项目所有价差，只认 code 严格相等

    怎么复现整条链路只用了 2 个 MCP 工具，任何申请到 Token 的账号都能跑出同样的表

    调用顺序

    • 1 · query-nearby-stores 按城市 + 地标取门店，过滤营业中
    • 2 · query-meals 逐店拉实时菜单（orderType=1, beType=1）
    • 3 本地按 code 建矩阵，算中位价与价差
    • 4 渲染成本页

    命令

    # 1. 采集（8 城 × 4 店）
python skill/scripts/collect_batch.py breakfast 4

# 2. 分析
python skill/scripts/analyze.py \
  --snap data/snapshot-breakfast.json \
  --out data/analysis.json

# 3. 出报告
python skill/scripts/render.py \
  --analysis data/analysis.json \
  --out demo/index.html
